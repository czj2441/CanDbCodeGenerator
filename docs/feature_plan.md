# UI 迭代优化方案

> 基于 CanMatrix 全组件 UI 审查，从产品可用性、实用性角度提出的迭代改进方案。

---

## P0 — 高优先级（日常效率瓶颈）

### 1. 文件浏览器搜索/筛选

- **现状**：`FileBrowser.vue` 文件列表无搜索能力，文件多时难以定位
- **方案**：Header 区增加搜索输入框，按文件名实时过滤（纯前端计算）

### 2. 文件浏览器表头 i18n

- **现状**：`FileBrowser.vue#L31-L36` 表头 `文件名/报文/信号/修改时间/状态/操作` 硬编码中文
- **方案**：替换为 `t('browser.colName')` 等 i18n 键

### 3. 报文列表搜索过滤

- **现状**：`MessageList.vue` 左侧窄栏（240px）无搜索，报文多时难以快速定位
- **方案**：sidebar-header 下方增加迷你搜索框，按报文名/ID 实时过滤

### 4. 信号表格冻结列

- **现状**：`SignalEditorTab.vue` 12 列一字排开，小屏幕需大量水平滚动
- **方案**：
  1. 冻结首列（名称）+ 末列（操作），中间列自由滚动
  2. 提供"列显示/隐藏"设置，用户按需关闭不常用列（如 min/max/comment）

### 5. 全局快捷键帮助面板

- **现状**：Ctrl+Z/Y/S 等快捷键散落各组件，用户无从得知完整列表
- **方案**：增加 `?` 或 `F1` 触发快捷键帮助 Modal，列出所有可用快捷键

## P1 — 中优先级（专业体验提升）

### 6. TopBar 按钮分组

- **现状**：`TopBar.vue#L1-L38` 所有按钮一字排开，仅靠 spacer 分隔，无功能分组视觉
- **方案**：用细竖线 `|` 或 `btn-group` 容器分组：
  - 导航组：← 返回
  - 编辑组：撤销 / 重做
  - 文件组：新建 / 导入 / 导出 / 保存 / 另存为
  - 系统组：主题 / 日志 / 状态

### 7. TopBar Toast i18n 统一

- **现状**：`TopBar.vue` 中多处硬编码中文：`不支持的文件格式`(L264)、`成功导入`(L294)、`导入失败`(L296)、`保存失败，导入已取消`(L308)、`保存成功`(L396) 等
- **方案**：抽取为 `toast.importSuccess`、`toast.importFailed`、`toast.saveSuccess` 等 i18n 键

### 8. 文件列表排序

- **现状**：文件顺序完全依赖后端返回，用户无法排序
- **方案**：表头增加可点击排序（按名称/时间/报文数），纯前端实现

### 9. 报文拖拽排序

- **现状**：`MessageList.vue` 报文顺序固定，只能通过"添加"追加
- **方案**：支持 Drag & Drop 排序，操作后通过 WS 同步到后端

### 10. 报文右键菜单可见性

- **现状**：右键菜单（复制/粘贴/删除）只能右键触发，新用户不知道有这些功能
- **方案**：报文项 hover 时显示 `⋮` 更多操作按钮（点击弹出同样的菜单）

### 11. 信号表格内联编辑验证

- **现状**：`SignalEditorTab.vue` 输入框 blur 后直接提交，无即时验证提示（length=0、factor=NaN）
- **方案**：输入非法值时输入框边框变红 + 底部行内错误提示

### 12. 信号批量选中操作

- **现状**：只能逐行操作，无法框选多行批量删除或修改属性
- **方案**：增加 Shift/Ctrl 多选 + 批量删除按钮 + 批量属性编辑面板

### 13. 属性面板宽度可调

- **现状**：`SignalPanel.vue#L184` 固定 `width: 280px`，长名称/长注释显示不全
- **方案**：左侧边框加拖拽条（类似 LogPanel resize handle），范围 200-500px

### 14. 自动保存状态指示

- **现状**：StatusBar 只显示 `已修改` 文字，不知道是否已自动保存
- **方案**：增加 `已保存` / `正在保存...` / `已修改 · 未保存` 状态，保存后短暂显示 ✓ 图标

### 15. Undo/Redo 历史预览

- **现状**：撤销按钮只有 disabled/enabled 状态，不知道撤销会回退什么操作
- **方案**：按钮 tooltip 显示操作名称（如 `撤销: 修改信号 PTA01_AdVal`）

### 16. 文件浏览器空状态引导

- **现状**：空列表仅一行文字，新用户不知道下一步
- **方案**：空状态加一个大号"+ 新建项目"按钮 + 简要使用说明

### 17. 文件浏览器硬编码中文

- **现状**：`FileBrowser.vue` 中 `删除中...`(L13/L121)、`创建中...`(L144)、`... 等 N 个文件`(L114) 硬编码中文
- **方案**：统一走 i18n 键

## P2 — 低优先级（锦上添花）

### 18. 导出下拉键盘可达性

- **现状**：Export 下拉只能鼠标操作，无 Esc 关闭、无方向键导航
- **方案**：增加 Esc 关闭 + 方向键选择 + Enter 确认

### 19. 报文信号计数显示 i18n

- **现状**：`MessageList.vue#L17` `{{ m.signal_count }}s` 硬编码英文 `s`
- **方案**：使用 i18n 或改为更直观的图标

### 20. 信号拖拽排序

- **现状**：信号顺序由添加顺序决定，无法调整
- **方案**：行首增加拖拽手柄（≡ 图标），支持拖拽调整信号顺序

### 21. 报文 ID 输入优化

- **现状**：`MessagePanel.vue#L9` 要求手动输入 `0x` 格式十六进制，容易出错
- **方案**：输入框左侧固定显示 `0x` 前缀，或提供 hex/dec 切换

### 22. 主题切换过渡动画

- **现状**：切换明暗主题时颜色瞬间跳变，视觉冲击大
- **方案**：`data-theme` 切换时加 `transition: background-color 300ms, color 300ms`

### 23. Loading 进度信息

- **现状**：`LoadingOverlay.vue` 只有 spinner，无进度信息
- **方案**：可预估操作增加进度百分比或步骤描述（`正在解析 DBC...` / `正在生成代码...`）

---

## 优先级矩阵

| 优先级 | 改动项 | 影响面 | 工作量 |
|--------|--------|--------|--------|
| **P0** | #1-#5 文件搜索、报文搜索、表格冻结列、快捷键帮助、i18n 补全 | 日常使用效率 | 中 |
| **P1** | #6-#17 TopBar 分组、拖拽排序、内联验证、面板可调、状态指示等 | 专业体验 | 中高 |
| **P2** | #18-#23 键盘可达性、信号拖拽、主题过渡、loading 进度等 | 锦上添花 | 低中 |

## 迭代建议

- **Sprint 1**（P0）：拆成 2-3 个小 PR 快速落地，重点解决搜索和 i18n
- **Sprint 2**（P1 上半）：TopBar 重构 + 拖拽排序 + 内联验证
- **Sprint 3**（P1 下半）：面板可调 + 批量操作 + 状态指示
- **Backlog**（P2）：按优先级穿插到后续迭代
